# AI Agent Bad API Call Audit Log

This example simulates an AI agent interacting with a product inventory API. It demonstrates how an AI agent, due to a flaw in its logic or interpretation, might make an unintended "bad" API call (e.g., deleting a product instead of updating its quantity to zero). The audit log records all actions, including the bad one, highlighting that audit logs are reactive records of events rather than proactive prevention mechanisms.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`.
